# Проверка работы

## Проверка доступности узла

- адрес назначения — **10.131.0.200**
- команда **ping** получила 3 ответа из 4
- первый пакет был потерян
- последующие ответы подтвердили доступность узла

![Проверка доступности узла 10.131.0.200](Screenshot_11.png){ width=80% }

## Трассировка маршрута

- **10.128.6.1** — шлюз сети «Донская»
- **10.128.255.254** — сторона GRE-туннеля в Пизе
- **10.131.0.200** — конечный узел Университета г. Пиза

## Таблица маршрутизации «Донская»

- **10.131.0.0/24**
- получен через **OSPF**
- следующий переход — **10.128.255.254**
- интерфейс выхода — **Tunnel0**

![Таблица маршрутизации маршрутизатора «Донская»](Screenshot_12.png){ width=80% }

## Таблица маршрутизации Университета г. Пиза

- сеть **10.131.0.0/24** подключена напрямую
- адрес шлюза **10.131.0.1** находится на **FastEthernet0/0.401**
- удалённые сети получены через **OSPF**
- маршрут по умолчанию направлен через **192.0.2.1**

![Таблица маршрутизации маршрутизатора Университета г. Пиза](Screenshot_13.png){ width=80% }
